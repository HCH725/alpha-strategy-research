## Economic mechanism

### Source-reported

Dual-confirmation oscillation fade with a symmetric risk box, two-sided. The Stochastic K line and the RSI must agree: both below 20 prints the long (oversold) condition, both above 80 prints the short (overbought) condition, so one indicator's whipsaw alone cannot fire. A 100-point stop and a 100-point target bracket every position on both sides. The prose block adds an explicit risk admission: parameters tuned to one product/frame may not transfer, and Stochastic-type logic bleeds in violently trending markets — this machine is built for range-bound oscillation, not trend. The source ships no sample statistics, trade count, fee basis, win rate, or performance figure of any kind — a full-token census for Sharpe/胜率/win-rate/profit-factor/drawdown/annualized returns zero performance tokens — no source-reported performance is adopted or restated.

### Research interpretation

Agreement-gated mean-reversion switch with a floating symmetric collar, event-driven, two-sided, flat except while both oscillators agree. Unlike clock-only records (`monday-drift` — UTC day-of-week + hour predicates with time exits), there is no clock predicate anywhere here: quiet mid-range bars print nothing without joint oversold/overbought agreement. Unlike edge-cross records (`fmz-vwma3-sma266-cross-delay3` — VWMA3/SMA266 `crossover`/`crossunder` edges with a 3-bar fuse and a latched 1000/200 tick box, two-sided 1m), the trigger here is a LEVel agreement (`rsi < 20 and k < 20`), not a cross edge; there is no fuse; and the box floats every bar instead of latching at the fill. Unlike gate records that admit a cross only under a second indicator (`alma-cross-volume-gate` — ALMA60/120 cross admitted only when a volume-oscillator gate reads positive, two-sided 1d), agreement here is not a gate on a cross — the joint threshold breach IS the signal, and there is no cross anywhere in the file. Unlike breakout records that also read Stochastic (`gauss-stochrsi-breakout` open PR — Gaussian-channel breakout admitted by a StochRSI gate, long-flat, BNB 1d; `fxengineering-higher-high-dip-breakout-stochk-exit` — dip-breakout entries with a Stoch-K exit only, long-flat 1h), this machine fades extremes in both directions (never breaks out, never exits on Stochastic alone) and brackets both sides symmetrically. Unlike smoother-state records (`dss-bressert-double-smoothed-stochastic` — double-smoothed %D trigger latch, two-sided 2h; `wvf-stochrsi-filtered-bottom` — Williams-VIX-Fix plus StochRSI filter for bottom longs, long-flat 1d), both oscillators here are first-order (single smoothing on K, plain Wilder RSI) with fixed 20/80 rails and a fixed ±100 box, and the stance is two-sided on 1m. Unlike the sibling ChaoZhang record (`fmz-vwma3-sma266-cross-delay3` — same author, same mirror head, adjacent modification stamps), the indicator family (RSI+Stoch vs VWMA+SMA), the trigger class (level agreement vs delayed cross edge), the box dynamics (floating vs latched), and the risk symmetry (100/100 vs 1000/200) are all materially different mechanisms sharing only authorship and venue.

## Signal — Gate 1, fully pinned derivative

Index completed UTC minute bars `t = 0, 1, ...` with real Binance BTC-USDT futures `O[t], H[t], L[t], C[t]` (`V[t]` is never read — no volume input of any kind). A bar with missing/nonfinite/non-positive prices, or with `H < max(O,C)` / `L < min(O,C)`, is invalid; never interpolate. All inputs pinned at source defaults: `fastK = 14`, `slowK = 3`, `slowD = 3`, `overSold = 20`, `overBought = 80`, `rsiPeriod = 14`, `stopLoss = 100`, `takeProfit = 100` (any other values are a different, unpinned rule).

- **Raw stochastic `ST[t]` (t ≥ 13):** `100 · (C[t] − LL14[t]) / (HH14[t] − LL14[t])` with `LL14`/`HH14` the trailing 14-bar low/high extremes (Pine `stoch` — exact windowed extremes, no seed state; flat 14-bar windows define `ST = 50` by the file's evident constant-guard reading — disclosed; such windows never occur on BTCUSDT 1m and the pin governs them analytically).
- **K `K[t]` (t ≥ 15):** exact 3-bar mean of `ST[t−2..t]` (Pine `sma` — non-recursive, no seed state; `na` before index 15, and `na` comparisons never fire — disclosed). The `D = sma(K, 3)` line is computed in the file but never read by any order — inert display, dropped by adaptation (6).
- **RSI `R[t]` (t ≥ 13):** Wilder-RMA RSI over 14 closes (Pine `rsi` — recursive: needs the 14-bar seed plus convergence margin; `na` before index 13).
- **Level decisions (t ≥ 15 by construction, actionable only t ≥ 59 — see warmup):** long predicate `LONG[t] = R[t] < 20 AND K[t] < 20`; short predicate `SHORT[t] = R[t] > 80 AND K[t] > 80` (file-literal threshold conjunctions on both sides). Single evaluation per completed bar per side by construction; both predicates on one bar are arithmetically impossible (`R < 20` and `R > 80` cannot co-hold — disclosed).
- **Floating bracket legs (re-anchored every completed bar from that bar's close, never latched):** while long through bar `d`, `TP[d] = C[d] + 100.0`, `SL[d] = C[d] − 100.0`; while short, `TP[d] = C[d] − 100.0`, `SL[d] = C[d] + 100.0` (100/100 are price points in USDT — `stop=`/`limit=` take prices, never ticks, so no tickSize conversion applies; levels are tickSize-snapped at 0.10 — the record's sole precision pin). Levels move with price every bar (floating collar, NOT a ratchet, NOT latched).
- **Exit precedence (explicit researcher pin):** each held bar resolves the floating box first-touch against the bar's `H/L` with the **stop-first** same-bar rule (both touched → stop price wins). An opposite level predicate arriving while holding REVERSES the book at the next open (close at next-open, open opposite at the same next-open, old floating pair cancelled, new pair armed from the next bar's close) — Pine `pyramiding = 0` default reversal pinned as an explicit gate, same pin class as the merged two-sided Super-Scalper/SMMA17/PowerZone/candle-size/staircase/VWMA records.
- **Gap/contiguity pin (explicit):** the 14-bar stoch window, the 3-bar K smoothing, and the RSI recursion must be fed by consecutive valid calendar bars; a gap pauses signals until the windows refill past the 60-bar warmup (no interpolation, no carry-forward of stale windows — disclosed).

**Direction (Gate 2):** `Compra`-to-open / reverse-to-close on the long leg; `Venta`-to-open / reverse-to-close on the short leg. Both legs ship in the file (`strategy.long` + `strategy.short`). The two-sided stance on the pinned futures venue is realistic and needs no spot-short permission. No hedge, no cross-market trade.

**Risk (Gate 3, explicit):** symmetric ±100-USDT floating box per side (≈0.27% at stanza-window ~37k BTC — researcher arithmetic, not a source claim). Fixed 100-USDT stop and fixed 100-USDT target re-anchored at each held bar's close (1:1 nominal). No trailing ratchet, no breakeven move, no time stop, no partial exit, no averaging, no forced end-of-data liquidation, no silent executor default. An end-of-sample open position is marked at the last real valid close, not closed with an invented fill.

**State (Gate 4):** `FLAT`, `LONG`, `SHORT` — plus no counters (stateless signal apart from the RSI recursion seed). Initialize `FLAT` after 60 valid completed bars. Entries fire only from confirmed `FLAT` (fresh joint predicate) or as an explicit reversal from the opposite held side; a missing/failed/unconfirmed fill **halts** this research run, never synthesizes inventory. A pending order prohibits additional actions. **No DCA/safety orders (explicitly disabled — the downstream 6%+6%+6% house overlay is not active in this admission and never silently overrides single-unit semantics)**, no pyramiding, no concurrency, no compounding. No cooldown is specified (explicitly none, not invented) — re-entry needs a fresh joint predicate after a flat print.
