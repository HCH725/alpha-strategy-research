## Economic mechanism

### Source-reported

Congestion-breakout speculation on a noise-filtered grid (mirror the source titles): because a P&F chart `evolve[s] only when there is a price change big enough to warrant a new X, a new O, or a new reversal column`, sideways chop below the reversal distance prints nothing at all, while `a sequence of O-Columns with equal lows marks a clear support level` and `a sequence of X-Columns with equal highs marks a clear resistance level`. StockCharts converts those certified levels into the two most-basic systems — the X-Column break `above the high of the prior X-Column` buys demonstrated demand strength, the O-Column break `below the low of the prior O-Column` sells demonstrated supply weakness — with the wider triple/spread/ascending/quadruple patterns offered as better-established (and explicitly unadopted here) variants.

### Research interpretation

Box-grid breakout capture on a single 24/7 instrument, both sides coded. Unlike the pool's Kagi flip (which recolors on any 4% anchor-relative move certified by peak/trough memory, close-only), this system can only change state when a full 1%-box column extreme takes out the adjacent same-side column extreme — a 2.9% drift that never completes a 3-box reversal prints no column at all, and an X-Column that rises without exceeding the prior X-Column top is an explicit no-op. Unlike the pool's Three-Line-Break flip (which certifies reversals through 3+-line runs and fences alternation), this system carries no run gate — selectivity comes solely from the box grid plus the prior-column reference: the bet is that certified double-top / double-bottom breaks on daily BTCUSDT precede multi-day directional drift often enough to survive the source-admitted whipsaw (`most prone to whipsaw and failure`, both sides, inherited undisguised — see Negative evidence), with no stop, target, or cooldown to dampen it.

## Signal

Exact rule as pinned (1% box, reversal 3, High-Low method, strict continuation / inclusive reversal — any other box size, scaling form, reversal amount, price method, tolerance, filter, or stop is a different, unpinned rule):

- Notation: completed daily bars with high `H[i]` / low `L[i]`; box index `b(P) = floor(ln(P / A) / ln(1.01))` with anchor `A` = first available close (frozen); column state `(side, E)` with `side ∈ {X, O}`, `E` = current extreme box (top box for X, bottom box for O); references `PX` (extreme box of the most recent completed X-Column, undefined until the first X-Column completes) and `PO` (extreme box of the most recent completed O-Column, undefined until the first O-Column completes).
- Seeding (source-normalized from the worked example `The chart has to start somewhere. We will assume prices are falling and plot O's...`): seed an O-Column at `E = b(C[0])` on the first available close. Position stays flat until the first signal (the seed column is continuity, never a signal — declared record rule).
- Per completed bar `i` in strict time order (High-Low priority, pinned):
  - If `side == X`: if `b(H[i]) > E` (strict — continuation): `E = b(H[i])`; then BUY check — iff `PX` defined and `E > PX` (strict) and the pre-update extreme `E_prev <= PX`, fire BUY (first-cross of the prior-X high within this column). Else (no continuation) iff `b(L[i]) <= E − 3` (inclusive — `equal to or greater than the reversal distance`): complete the X-Column (`PX = E`); open an O-Column with `E = b(L[i])` (the Day-6 `starting one below the high of the previous column` landing, in index form); then SELL check — iff `PO` defined and `E < PO` (strict) and the just-completed column is not the reference itself (i.e. this new O is a distinct column from the `PO` column), fire SELL only as a first-cross (see firing rule). Else: explicit no-op — no state change, no signal (`Ignore both...`).
  - If `side == O`: mirror. If `b(L[i]) < E` (strict — continuation): `E = b(L[i])`; then SELL check — iff `PO` defined and `E < PO` (strict) and `E_prev >= PO`, fire SELL. Else iff `b(H[i]) >= E + 3` (inclusive): complete the O-Column (`PO = E`); open an X-Column with `E = b(H[i])`; then BUY check — iff `PX` defined and `E > PX` (strict) on a distinct new column, fire BUY only as a first-cross. Else: explicit no-op.
  - Firing rule (first-cross per column per reference, deterministic): a BUY fires iff this bar's update is the first update of the current X-Column with extreme strictly beyond `PX` as it stood when the column opened; further extension of the same column never refires; a new BUY requires a new X-Column (after an intervening reversal) breaking above the then-current `PX`. SELL mirrors with `PO`. Because the column extreme is monotonic within a column and the reference is frozen for the column's life, first-cross is well-defined and single-fire by construction.
- Position target (source signal pair wired to the flip book): at the close of each completed bar `i` (post-warmup), the target for the next bar is long iff this close printed a BUY first-cross; short iff it printed a SELL first-cross; else unchanged (hold current side; flat only before the first-ever signal). Orders fire for the next bar's open: flat→long buys at next open on BUY; flat→short sells at next open on SELL; long-held + SELL flips full long to full short in one step at next open; short-held + BUY flips full short to full long in one step at next open. Same-column non-cross extensions, sub-reversal chop, and ignored-high/low bars are no-ops (single-unit, no adds — declared port of one-event-per-bar-boundary). At most one order event per bar boundary; no intrabar evaluation, no intrabar orders, no partials.
- Mutual exclusion (proven, not assumed): each bar resolves to exactly one column type (continuation-first priority consumes at most one of high/low; reversal opens exactly one contra column; else no-op), BUY fires only from X-columns and SELL only from O-columns, and the firing rule is first-cross — both legs can never fire on the same close and no priority ruling is owed.
- Degenerate tape (proven, not assumed): a zero-range history never satisfies any strict continuation inequality and never reaches the inclusive 3-box reversal distance, so no column completes, no reference forms, no first-cross prints, and the book stays flat; no extra guard is owed.
- Risk legs (declared researcher posture, matching all four rule sources' shipped absence of risk): no stop-loss, no take-profit, no trailing, no time exit — the sole position-changing paths are double-top / double-bottom first-crosses. A vertical adverse move on/after the entry bar is held in full until the opposite first-cross prints. Price-objective counts (horizontal/vertical) are explicitly not adopted (`just rough guidelines`). This is the coded trade, disclosed, not a tunable parameter here.
- Direction: two-sided flip system, always-in-market after the first signal, flat before it by construction.
