```text
class KeltnerWidthBreakout(Strategy):
    n = 20; atr_n = 10; mult = 2; width_n = 50
    def init(self):
        atr = _atr(self.data.High, self.data.Low, self.data.Close, self.atr_n)
        ema = _ema(self.data.Close, self.n)
        self.upper = self.I(lambda: ema + self.mult * atr, name="Upper")
        width = (ema + self.mult*atr - (ema - self.mult*atr)) / ema.replace(0,1e-10)
        self.width = self.I(lambda: width, name="Width")
        self.width_min = self.I(lambda: width.rolling(self.width_n).min(), name="WidthMin")
    def next(self):
        if self.width[-1] < self.width_min[-1]*1.1 and self.data.Close[-1] > self.upper[-2] and not self.position: self.buy()
        elif self.data.Close[-1] < self.upper[-1]*0.98 and self.position: self.position.close()
```

## Economic mechanism

### Source-reported

Volatility-contraction breakout timing, long side only. The machine waits for the Keltner channel width to compress to within 10% of its 50-bar minimum (low volatility), enters long on a close above the upper band (prior-bar rail), and ends the position when price falls 2% below the upper band. Between trigger and exit the machine holds its posture — a recovery that never prints 2% under the band keeps a long alive, and chop that never compresses never enters. The equity-index universe and the unmodeled-costs stance are source facts, not this record's venue or economics. No performance figure is carried anywhere.

### Research interpretation

Squeeze-gated breakout-in, band-trailing-out — the only pool machine that pairs a genuine compression gate with a band-rail exit. Unlike the pool QT Keltner-Squeeze record (which breaks the same EMA20+2×ATR10 rail **ungated** and exits at the **SMA20** midline), this machine's entries are a strict subset (compression-gated) and its exits print on a wholly different rail (2% under the breathing upper band, not a static average) — the two event sets differ on both legs, never twins. Unlike Donchian rolling-extreme breakouts, the rail is manufactured (EMA plus two average true ranges) so entries key off volatility-normalized displacement rather than realized extremes; unlike the pool's momentum/ADX-gated Keltner cousins, the only gate is compression itself — no trend read anywhere. Unlike stop/trailing-stop machines, the exit carries no memory: `Upper[t]×0.98` is recomputed each bar from the live envelope, so the exit rail breathes with volatility instead of ratcheting — a sharp post-entry volatility expansion lifts the exit rail away (protection loosens exactly when chop arrives), while compression drags it tight under price. The failure mode is plain: a violent single-bar jump spikes ATR and kills its own squeeze gate (the planted single-jump tape prints 0/0 — the gate fails on the very bar that breaks out, disclosed, not patched); entries therefore fire on slow leak-ups during compression, never on gaps. A steady ±1%/day drift never compresses and never enters (planted ramp and bleed tapes: 0/0 ending FLAT — opportunity cost both ways, disclosed); a dead-flat tape never arms the strict excess (0/0 FLAT — disclosed); a sustained +1%/day climb enters once on the first post-warmup bar and holds with no stop (planted climb tape: 1/0 ending LONG — disclosed hold-by-construction, not patched); compression followed by a push and a real pullback prints the full round trip (planted squeeze-push-drop tape: 1/1 ending FLAT — entry fill t=114, exit fill t=136, disclosed).
