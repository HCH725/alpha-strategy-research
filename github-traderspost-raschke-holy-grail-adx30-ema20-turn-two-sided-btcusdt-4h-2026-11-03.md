## Economic mechanism

### Source-reported

Trend-continuation pullback setups: in a strong ADX-confirmed trend, price pulls back to touch the 20-bar average, then prints a turn bar back with the trend — marked HG bull (buy-the-dip) / HG bear (sell-the-rally). The file ships no performance figure, no trade rule, no market thesis — none adopted.

### Research interpretation

Unlike pool cross/fade siblings from this same file (80-20 climax locations with an ATR width gate; Turtle-Soup 20-bar sweep levels with an age gate; ODUP/ODDN gateless two-bar engulfs — all pure price-shape objects with no trend filter), this machine is the file's only **trend-filtered continuation** trigger: nothing fires unless ADX(14) reads above 30 with the DI pair signed the trade's way, and the entry times the resumption (touch plus turn bar) rather than the extreme itself. Unlike pool ADX cousins (DI-cross systems that trade the cross event; EMA-reclaim systems with multi-condition stacks), this trigger never trades a cross — it requires *sustained* strength plus a pullback that holds the average on a closing basis. Unlike the admitted Trost Holy-Grail record (different source, ADX18>28 with a WMA11 straddle, dual slope gates, trigger-high breakout entry, cancel-pair exits, long-only 1d spot — see Negative evidence), this machine drops every slope/straddle/trigger/cancel element, keeps only the Raschke-file touch-plus-turn construction at source-default 14/30/20 lengths, trades two-sided on 4h futures, and exits only through the researcher 2%/4% box or an opposite setup. Live-window rate is 35 post-warmup predicate bars per 1,499 4h bars (11 bull-leg / 24 bear-leg), driving 17 opens / 17 closes (11 SL / 4 TP / 2 reversals) — the slow-selective character (about one setup per 43 bars) is structural, not tuned.

## Signal — Gate 1, fully pinned derivative

Index completed UTC 4-hour bars `t = 0, 1, ...` with real Binance BTC-USDT futures `C[t]`/`O[t]`, `H[t]`/`L[t]`. A bar with missing/nonfinite/non-positive OHLC, or `H < max(O,C)` / `L > min(O,C)`, is invalid for signals. All constants are source-default literals at `enHG=true`.

- **EMA20 (researcher seeding pin, disclosed — Pine `ta.ema` needs an explicit seed to be reproducible):** `alpha = 2/21`; `EMA[19] = mean(C[0..19])`, then `EMA[t] = alpha*C[t] + (1-alpha)*EMA[t-1]`; undefined for `t < 19`.
- **DMI(14,14) (researcher seeding pin, disclosed — Wilder RMA seeded with simple means, the same class the admitted Trost record pins for Pine `rma` semantics):** from `t ≥ 1`, `TR = max(H-L, |H-C[1]|, |L-C[1]|)`, `+DM = H-H[1]` iff positive and dominant else 0, `−DM` mirrored; smoothed `S_TR/S_P/S_M` are RMA(14) seeded with the mean of values `1..14` (first defined `t = 14`); `DI+ = 100*S_P/S_TR`, `DI− = 100*S_M/S_TR` (defined when `S_TR > 0`); `DX = 100*|DI+−DI−|/(DI+ + DI−)`; `ADX` is RMA(14) of DX seeded with the mean of the first 14 defined DX values (first defined `t = 27` on full history — verified on tape path this cycle).
- **Predicates (actionable only t ≥ 100, at bar `t`'s close, Pine-faithful):** `bull[t] = (ADX[t]>30.0) and (DI+[t]>DI−[t]) and (L[t]<=EMA[t]) and (C[t]>EMA[t]) and (H[t]>H[t-1])`; `bear[t] = (ADX[t]>30.0) and (DI−[t]>DI+[t]) and (H[t]>=EMA[t]) and (C[t]<EMA[t]) and (L[t]<L[t-1])`. Pre-warmup bars flat by record rule; every na/degenerate/touch-tie bar is an explicit neither-fire hold. Strict legs match source exactly (equality never fires); the two touch legs are source-literal non-strict comparisons.
- **Latched box (researcher-designed, fixed at fill-average `A`, never moved):** long `SL=A×0.98`, `TP=A×1.04`; short mirrored `SL=A×1.02`, `TP=A×0.96`.
- **Resolution (explicit researcher pin):** entries fill next-bar-open MARKET; each held bar `v` (fill bar +1 onward) evaluates at its close in code order — opposite setup first (reversal dominates: close old and open new at the same next open; tie bars defensively hold per the impossibility proof), else SL-touch, else TP-touch (`H/L` vs latched levels); SL+TP co-fire is one flat close (stop wins). Single position, no adds: same-side refire is a no-op (verified on tape).
