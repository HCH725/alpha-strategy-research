## Economic mechanism

### Source-reported

Failed-breakout fade off a mother-bar balance: a quiet inside bar coils inside its mother range; a later bar pokes past an edge but cannot hold the break and closes back inside — the breakout side found no continuation and the balance reasserts, often resolving the opposite way. The 5% buffer exists to filter marginal closes that barely poke past the edge. The file ships no performance figure, no trade rule, no market thesis — none adopted.

### Research interpretation

Unlike the pool's admitted FMZ inside-bar-failure record (a stateless fixed 3-bar window: containment on bars t−2/t−1, probe-plus-close-back on bar t, 3-bar time exit — see Negative evidence), this machine is **stateful**: the mother box persists indefinitely until a buffered confirmed breakout kills it, so a FIB can fire many bars after the mother printed, and one box can emit consecutive FIBs. Unlike the same-file admitted siblings (20-bar sweep fades with an age gate; 80-20 climax locations with an ATR gate; gateless two-bar engulfs; ADX-gated EMA-touch continuation — all stateless single-bar predicates), this is the file's only setup with cross-bar memory plus a three-way poke/breakout/buffer trichotomy per edge. Unlike breakout-follow records (Donchian, Darvas, NR7, the admitted forven inside-bar-breakout-continuation long), this system bets the other way: clean buffered breakouts that close through the edge fire nothing by construction. Live-window rate is 228 post-warmup predicate bars per 1,499 4h bars (97 bull-leg / 131 bear-leg), driving 110 opens / 109 closes (50 SL / 17 TP / 42 reversals) — a busy fade-and-reverse character (about one setup per 6.6 bars) that is structural, not tuned.

## Signal — Gate 1, fully pinned derivative

Index completed UTC 4-hour bars `t = 0, 1, ...` with real Binance BTC-USDT futures `C[t]`/`O[t]`, `H[t]`/`L[t]`. A bar with missing/nonfinite/non-positive OHLC, or `H < max(O,C)` / `L > min(O,C)`, is invalid: explicit neither-fire hold with box state untouched (researcher invalid-bar pin, disclosed). All constants are source-default literals at `enFID=true`, `ibBreakBufPct=5.0`.

- **Box state (Pine-sequential, source-order):** `consolOn=false`, `top/bot=na` initially. For each bar `t` in order: if `consolOn`, `buf=(top−bot)×0.05`; if `H[t]>top`: `C[t]>top+buf` closes the box, `C[t]≤top` fires **bear**, else buffer-hold; elif `L[t]<bot`: `C[t]<bot−buf` closes the box, `C[t]≥bot` fires **bull**, else buffer-hold. Then `newInside = (H[t]<H[t−1] ∧ L[t]>L[t−1]) ∧ ¬consolOn` using the UPDATED `consolOn`; if so, `top=H[t−1]`, `bot=L[t−1]`, `consolOn=true`. Mother range is strictly positive whenever a box arms (the inside bar is strictly smaller), so `buf>0` always — no degenerate zero-buffer case, pinned defensively.
- **Predicates (actionable only t ≥ 100, at bar `t`'s close):** `bull[t]` / `bear[t]` as computed above. Pre-warmup bars flat by record rule. Co-fire structurally unreachable (single-branch `if/elif`).
- **Latched box (researcher-designed, fixed at fill-average `A`, never moved):** long `SL=A×0.98`, `TP=A×1.04`; short mirrored `SL=A×1.02`, `TP=A×0.96`.
- **Resolution (explicit researcher pin):** entries fill next-bar-open MARKET; each held bar `v` (fill bar +1 onward) evaluates at its close in code order — opposite setup first (reversal dominates: close old and open new at the same next open), else SL-touch, else TP-touch (`H/L` vs latched levels); SL+TP co-fire is one flat close (stop wins). Single position, no adds: same-side refire is a no-op (verified on tape — consecutive same-box FIBs while holding are ignored).
