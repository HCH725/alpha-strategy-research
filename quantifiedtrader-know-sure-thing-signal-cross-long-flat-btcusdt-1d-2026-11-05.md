class KnowSureThing(Strategy):
    r1,r2,r3,r4 = 10,15,20,30
    s1,s2,s3,s4 = 10,10,10,15
    sig_n = 9
    def init(self):
        c = pd.Series(self.data.Close)
        kst = 100*(c.pct_change(self.r1).rolling(self.s1).mean()*1 + c.pct_change(self.r2).rolling(self.s2).mean()*2 + c.pct_change(self.r3).rolling(self.s3).mean()*3 + c.pct_change(self.r4).rolling(self.s4).mean()*4)/10
        self.kst = self.I(lambda: kst, name="KST")
        self.signal = self.I(lambda: kst.ewm(span=self.sig_n, adjust=False).mean(), name="Signal")
    def next(self):
        if crossover(self.kst, self.signal) and not self.position: self.buy()
        elif crossover(self.signal, self.kst) and self.position: self.position.close()

## Economic mechanism

### Source-reported

Cycle-timing composite, long side only. Four rates of change (10/15/20/30 bars) are each smoothed (10/10/10/15 bars) and combined with increasing weights (1/2/3/4) so longer cycles dominate; the composite's EMA-9 signal line defines the trigger — the position opens when the composite crosses above its own signal (broad-cycle upturn confirmed across all four horizons) and ends it on the reverse cross. ### Research interpretation

Quad-horizon ROC composite raced against its own signal line — the weight-laddered cousin of the pool's summed-ROC machines and the composite sibling of the pool's dual-line cross family. Unlike raw-momentum cross systems (the lane's ROC-Crossover dual-ROC5/20, which races two unsmoothed ROCs against each other), every ROC leg here is pre-smoothed and the trigger never reads a raw ROC — entries fire on composite-vs-EMA-signal polarity flips, so single-horizon spikes that dominate one raw leg are diluted 1-2-3-4 across the stack before they can arm an edge. Unlike zero-state level machines (Coppock's `curve > 0` hold, ROC-sign holds) the entry is a one-bar cross edge — consecutive above-signal bars enter exactly once on the crossing bar and hold silently after. Unlike fixed-level oscillators (DPO-vs-zero, CMO-vs-±80) the trigger line moves — it is the composite's own EMA-9, so entries key off composite acceleration relative to its recent self, not off an absolute level. The failure mode is plain: a dead-constant tape pins every ROC at exact zero, so composite and signal both print exact zero forever and the strict edge never arms (planted dead-flat tape: 0 entries / 0 exits ending FLAT — disclosed, not patched); dead-smooth geometric ramps pin the composite at a constant print the EMA signal converges onto, so only floating-point-ripple crossings at 4-decimal equality can fire (planted sustained ±1%/day tapes print 2 entries / 1 exit ending LONG on prints equal to four decimals — disclosed fp-ripple degeneration by construction, deterministic, not patched); chop that whips the composite around its signal prints repeated cross/reverse round trips with no stop and no profit-taking leg (the planted flat/dip/recover/decay trip exercises entry, exit, and re-entry: 2 entries / 1 exit ending LONG, first entry t=134, last entry t=235 — disclosed).
