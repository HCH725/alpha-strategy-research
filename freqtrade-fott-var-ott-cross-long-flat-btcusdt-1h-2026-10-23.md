## Economic mechanism

### Source-reported

The source claims only what its code prints: ride the VAR adaptive average while it sits above its own OTT trailing band (enter on the upward cross), exit shorts on the mirror cross, and cut both sides when ADX prints above 60 (a overheated-trend exit). A stepped ROI table (10% immediate, then unreachable-higher middle legs, 5%/2.5% late legs), a −26.5% stoploss, and a +5%-trigger/10%-delta trailing stop backstop every position. The file ships hyperopt-result comments (trade counts, profits, durations) — this record adopts no source-reported performance (see Evidence) and retunes nothing.

### Research interpretation

Adaptive-band momentum entry with a single-key lock, long-only in derivation. Unlike SMA/EMA cross records (fixed-smoothing averages crossing each other), the VAR leg re-weights itself every bar by the absolute Chande Momentum Oscillator: dead tape (|CMO| near 0) freezes VAR, directional tape (|CMO| near 1) lets VAR chase price with a 2-period EMA gain — so the cross fires only when tape both moves AND agrees with itself for 9 bars. Unlike stop-flip records that trade price against a trailing rail, this rule never compares price to the band directly: the trigger is the smoothed average VAR crossing its own band OTT, a second-order agreement condition. The coded consequence is a buyer of confirmed adaptive-trend emergence that banks a fixed +10% or holds to the data end.

## Signal

Exact rule as pinned (any other lookback, percent, seed, shift, threshold, risk leg, fill, frame, book, or leg combination is a different, unpinned rule). All identifiers below are the program's own:

```text
ud1[t]       = max(close[t] - close[t-1], 0)
dd1[t]       = max(close[t-1] - close[t], 0)
UD[t]        = sum(ud1[t-8 .. t])                        // rolling 9
DD[t]        = sum(dd1[t-8 .. t])                        // rolling 9
CMO[t]       = abs((UD[t] - DD[t]) / (UD[t] + DD[t]))    // 0/0 -> NaN -> fillna(0)
alpha        = 2 / 3
Var[t]       = alpha*CMO[t]*close[t] + (1 - alpha*CMO[t])*Var[t-1]   // Var = 0 before index 2
fark[t]      = Var[t] * 0.014
newlong[t]   = Var[t] - fark[t];  newshort[t] = Var[t] + fark[t]
longstop     = whole-frame ratchet from 0.0: keep max(newlong, prior) while Var above prior else reset to newlong
shortstop    = whole-frame ratchet from 1e18: keep min(newshort, prior) while Var below prior else reset to newshort
               // both ratchets applied as whole-frame vector updates, repeated len(df) times; deterministic pure
               // function of (Var, fark) — no closed-form simplification asserted, no randomness anywhere
xlong[t]     = (Var[t-1] > longstop[t-1]) & (Var[t] < longstop[t-1])
xshort[t]    = (Var[t-1] < shortstop[t-1]) & (Var[t] > shortstop[t-1])
trend/dir    = latch: 1 on xshort bars, -1 on xlong bars, else prior (dir seeds prior = 1 on first bar)
MT[t]        = longstop[t] if dir[t] == 1 else shortstop[t]
OTT_raw[t]   = MT[t]*201.4/200 if Var[t] > MT[t] else MT[t]*198.6/200
OTT[t]       = OTT_raw[t-2]                                     // shift(2), pinned
entry        = (var[t] > OTT[t]) & (var[t-1] <= OTT[t-1])       // crossed_above, enter_long = 1
```
