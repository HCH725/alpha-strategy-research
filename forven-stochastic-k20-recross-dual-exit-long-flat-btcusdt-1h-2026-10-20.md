## Economic mechanism

### Source-reported

### Research interpretation

Washed-%K snap-back machine, long-only, recross-in plus level-or-recross-out. Unlike the admitted `slow-stochastic-14-3-regime-recross` cousin (3-bar-smoothed SlowK, symmetric 20/80 recross flip, two-sided, SMA200 regime gate, `1d` next-open), this system reads the UNSMOOTHED FastK print — every entry/exit is decided by the raw 14-bar close-location of the current bar, so signals fire on noisier, earlier prints with no averaging lag and no trend-permission check whatsoever. Unlike the admitted same-family `forven-kdj-dual-gate` cousin (SMA-smoothed K/D plus the J-line rail conjunction J-zero AND K-cross), this system has no J line, no K/D cross, and no dual gate — a single %K level event suffices on each side. Unlike oscillator zero-cross cousins (ROC, PPO, MACD, AO), the traded object is a bounded 0–100 close-location gauge with asymmetric exits, never a signed spread around zero. Unlike stop-carrying records, the sole risk control is the dual exit — a position opened on a 20-recross is cut either the first bar %K touches 80 (level state, no cross needed) or the first bar %K recrosses down through 40, whichever prints first, with no stop, no target, and no equality-triggered entry.

## Signal

Exact rule as pinned (any other period, threshold, boundary, smoothing, exit leg, fill, frame, book, or ordering is a different, unpinned rule). All identifiers below are the program's own; the vectorized twin (lines 58–98) is the single source of truth and the scalar (lines 100–141) delegates to it:

```text
low14[t]        = min(low[t-13 .. t])              // rolling(14).min, causal
high14[t]       = max(high[t-13 .. t])             // rolling(14).max, causal
fastK[t]        = 100 * (close[t] - low14[t]) / (high14[t] - low14[t])   // UNSMOOTHED
dLine[t]        = mean(fastK[t-2 .. t])            // 3-bar SMA, diagnostic only
long_entry      = fastK[t-1] < 20  AND  fastK[t] >= 20     // 20-recross up
long_exit       = fastK[t] >= 80  OR  (fastK[t-1] >= 40 AND fastK[t] < 40)  // dual exit
guard           = fewer than 2 bars -> flat by source rule (fenced inside researcher 60-bar pin)
```

- %K construction (pinned `scanner.stochastic` body, quoted verbatim): `low_min = low.rolling(14).min()`, `high_max = high.rolling(14).max()`, `stoch_k = 100 * (close - low_min) / (high_max - low_min)`, `stoch_d = stoch_k.rolling(3).mean()`. Zero-denominator bars (`high14 == low14`) divide by `NaN` via `_safe_div` (`den.replace(0, np.nan)`) and rest flat — every comparison against `NaN` is `False`, so degenerate windows enter nothing and exit nothing by arithmetic, disclosed, not repaired. The first 13 bars of each rolling window are `NaN` by construction and likewise flat.
- Trade events: `entry_signal=True` with `direction="long"` on 20-recross bars (twin line 81, scalar lines 125–126); otherwise `entry_signal=False` with `exit_signal=bool(long_exit)` (twin lines 82–84). A bar printing exactly `fastK == 20.0` on the current side enters nothing (`curr >= 20` needs the cross leg `prev < 20` to also hold — a tape resting at exactly 20.0 has `prev < 20` false); a bar printing exactly `80.0` EXITS (level state `>=`, not a cross — touching 80 ends the long); a bar printing exactly `40.0` on the current side exits nothing (`curr < 40` strict).
- Direction: long-only for the pinned S020-BTC-LONG leg with an explicit pre-first-signal flat state plus the sub-2-bar guard flat. Both `direction=` literals resolve `"long"` under the pin (verified through the base-class normalizer); the twin's short branch (`short_entry`/`short_exit`, lines 88–91, gated by `k_exit_overbought`) is never selected by this leg — a two-sided reading would contradict the pinned roster entry. Resolution by book, never by engine ordering: a flat book ENTERS on a co-fire bar (the exit leg on a flat book is a no-op — there is no position to cut); an already-positioned book EXITS in full (the entry leg on a positioned book is a hold-no-op). Direct for the long leg, no margin short ever required: single-venue BTCUSDT perpetual `1h` completed bars with standard high/low/close prints.
