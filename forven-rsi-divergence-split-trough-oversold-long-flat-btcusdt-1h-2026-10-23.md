## Economic mechanism

### Source-reported

The source claims only what its code prints: wait for a bullish RSI divergence (price prints a lower low across the two halves of a 10-bar window while RSI prints a higher low at the same two trough bars) confirmed by current RSI below 30 (oversold), hold the long, exit when RSI rises above 70 (overbought). No sample, window, trade count, or cost basis ships — this record adopts no source-reported performance (see Evidence).

### Research interpretation

Oversold-divergence fade machine, long-only, close-only. The RSI leg signs each bar's momentum by exponentially smoothed gains versus losses (14-bar, causal); the divergence leg requires the same two trough bars to disagree (price down, RSI up) across a fixed 10-bar split — a bounded mean-reversion trigger that fires rarely (both a pattern AND an oversold print must coincide). The overbought exit harvests the snap-back while letting non-divergent chop hold flat. The failure mode is plain: a market that keeps bleeding with RSI pinned under 30 but without a fresh lower-low/higher-low alignment stays flat (no averaging down); a market whose RSI oscillates around 50 never arms; a divergent entry that immediately reverses down has no stop — the only exit is RSI > 70 or the sample-end truncation below. There is no time exit.

## Signal

Exact rule as pinned (any other RSI period, lookback, threshold, trough construction, risk leg, fill, frame, or book is a different, unpinned rule):

```text
rsi[t]  = 100 - 100/(1+rs[t]), rs = EWMA14(gain)/EWMA14(loss), gain/loss from close.diff(), min_periods=14, adjust=False  // causal
window  = last 10 closes + last 10 rsi prints, half = 5
trough1 = argmin(close[-10:-5]), trough2 = argmin(close[-5:])   // idxmin, earliest on ties
bull    = (close[trough2] < close[trough1]) and (rsi[trough2] > rsi[trough1])
entry   = bull and (rsi[t] < 30)   // strict, persistent per-bar state
exit_sig = (rsi[t] > 70)           // strict, persistent per-bar state
floor   = len(df) < 26 -> flat; isna(rsi[t]) -> flat (see Required data)
```

- Trade events: `entry=True` on every bar printing a qualifying divergence-plus-oversold pair, `direction` long-only; `exit_sig=True` on every bar printing RSI above 70. Each print is a persistent per-bar state, not a one-bar edge — a book already positioned treats further entry-state bars as hold-no-ops under the position pin below, and a flat book treats exit-state bars as no-ops.
- Exact boundaries (pinned semantics): entry uses strict `< 30`, exit uses strict `> 70` — a bar with `rsi == 30.0` or `rsi == 70.0` fires neither leg. Trough comparisons are strict (`<` for price, `>` for RSI) — equal lows fire nothing. Degenerate zero-loss windows print `avg_loss = 0 -> rs = NaN (via .replace(0, np.nan)) -> rsi = NaN`, and every `NaN < 30` / `NaN > 70` comparison is false, so degenerate bars deterministically fire neither leg (coded library behaviour, disclosed, never repaired). `idxmin` on ties returns the earliest index — deterministic, disclosed.
- Mutual-exclusion proof (no tie-break pin required): any entry bar has `rsi[t] < 30` while any signal-exit bar has `rsi[t] > 70` — mutually exclusive on every bar, degenerate, exact-boundary, or otherwise, so entry and signal-exit never co-print. No barrier legs exist to co-fire (all None below). The reviewer is never asked to invent an ordering.
- Direction: long-only. Zero short-leg tokens ship anywhere and every `Signal` returns `direction="long"` — a two-sided reading would contradict the file. The long-only book expresses unchanged on a spot venue (see Crypto portability).
- Exits and risk (explicit): the super-70 RSI state is the complete signal-closing set. No stop, no target, no trailing, no time exit — explicitly none further, not invented (zero such tokens ship in the file). No exit leg reads net profit, fees, or funding — fees change only the performance report, never whether an exit fires (disclosed).
- Position rule (predeclared researcher pin): single-unit, at most one open position per market; a positioned book treats further entry-state bars as hold-no-ops (no pyramiding, no averaging); a flat book treats exit-state bars as no-ops; re-entry re-arms on any qualifying divergence-plus-oversold bar after any exit, subject only to the once-per-decision-bar rule below (no additional cooldown beyond one decision bar — explicitly disclosed, not invented).
