## Economic mechanism

### Source-reported

The source claims only what its code prints: ride the trend by entering when the CMO-adaptive VAR average crosses above its OTT trailing-stop line, and stand aside when ADX(14) prints above 60 (trend-exhaustion readout); a hyperopt-generated ROI ladder, a −26.5% stoploss, and a 5%/10% trailing block backstop positions under Freqtrade execution. The file ships no market, sample, or performance claim — this record adopts no source-reported performance (see Evidence).

### Research interpretation

A two-piece trend system with opposite personalities: the entry is a hair-trigger — VAR hugs price through the CMO-adaptive coefficient, so the cross edge fires on the first decisive push through the trailing line; the exit is a sledgehammer — `adx > 60` is a rare, persistent exhaustion state, so a positioned book is carried through ordinary chop and only laid down when the trend meter pegs. Because the exit is a level, not an edge, whipsaw re-entry cannot machine-gun the book: the position pin below admits at most one entry per flat spell. Disabling the optimizer-generated risk block removes the file's 75%-at-30-minutes artifact and leaves the position's entire fate on the declared signal exit — an underwater drift that never prints `adx > 60` is held, not forgiven.

## Signal — Gate 1, fully pinned derivative

**Input:** one UTC Binance BTC-USDT spot 1h OHLCV stream `O[t],H[t],L[t],C[t],V[t]`; `t` is a completed bar. Validate finite `O,H,L,C>0`, `H>=max(O,C)`, `L<=min(O,C)`, `V>=0`, strictly consecutive open-time timestamps 3600 seconds apart, and no duplicates. Reject the run before feature preparation on any missing/invalid/nonconsecutive bar; no dropna bridging, synthetic bars or price fallback.

**VAR/OTT (source-faithful, file literals):** `pds=2`, `percent=1.4`, `alpha=2/3`. `ud1[t]=max(C[t]-C[t-1],0)`, `dd1[t]=max(C[t-1]-C[t],0)`; `UD[t]=sum(ud1[t-8..t])`, `DD[t]=sum(dd1[t-8..t])` (9-bar rolling sums); `CMO[t]=|UD[t]-DD[t]|/(UD[t]+DD[t])`, with `0/0 -> 0` (the file's `.fillna(0)`) then absolute value. `Var[0]=Var[1]=0`; for `i>=2`, `Var[i]=(alpha*CMO[i]*C[i])+(1-alpha*CMO[i])*Var[i-1]`. `fark[t]=Var[t]*0.014`; `newlongstop[t]=Var[t]-fark[t]`; `newshortstop[t]=Var[t]+fark[t]`. `longstop`/`shortstop` are the file's full-frame ratchet loop executed verbatim (`longstop` seeded `0.0`, `shortstop` seeded `999999999999999999`, iterated exactly `len(sample)` times over the admitted contiguous sample — prefix-stable per the probe above, NaN comparisons false). `xlongstop[t]=(Var[t-1]>longstop[t-1])&(Var[t]<longstop[t-1])`; `xshortstop[t]=(Var[t-1]<shortstop[t-1])&(Var[t]>shortstop[t-1])`; `dir` starts `1` with `xshortstop->1` / `xlongstop->-1` latching; `MT[t]=longstop[t]` if `dir[t]==1` else `shortstop[t]`; `OTT_raw[t]=MT[t]*201.4/200` if `Var[t]>MT[t]` else `MT[t]*198.6/200`; **`OTT[t]=OTT_raw[t-2]`** (the file's two-bar shift — the decision bar reads the line fixed two bars earlier). `ADX[t]=TA-Lib ADX(H,L,C,14)` (explicit period, Wilder smoothing). NaN-leading comparisons and edges are false, so pre-seed bars could never fire in any case.

**Completed-bar long entry predicate `E[t]`** (exact edge, no epsilon): `XUP(var,ott)[t] = (var[t]>ott[t]) & (var[t-1]<=ott[t-1])` (the verified `crossed_above` primitive, `technical@78061e9` vendor `indicators.py`, 20422 bytes, read this cycle), with `t>=60`, every required feature valid, no pending order, FLAT and re-arm state true. No volume/funding/OI/mark-price read anywhere in the gating path.

**Signal exit `X[t]`** (persistent state, strict): `ADX[t] > 60` — true on every bar the exhaustion level holds, not a one-bar edge. An open LONG closes on the first `X[t]` bar with `t` past the entry fill bar.

**Co-fire pin (resolved by position, disclosed, not repaired):** `E[t]` and `X[t]` can co-print (edge plus hot ADX on the same bar). Under the single-unit pin a FLAT book treats any co-print bar as entry (the exit leg needs a position and is a no-op without one — no same-bar round-trip), while a LONG book treats it as exit-close and ignores the entry edge (no pyramiding). Entry and exit therefore never execute on the same bar in the same direction of travel. ROI/stop legs do not exist in this derivative, so no further ordering is invented.

**Direction (Gate 2):** BUY only; SELL only to close the confirmed long. No short, borrowing, futures, hedge, leverage, negative inventory or cross-market trade. The file's `enter_short`/`exit_short` legs are explicitly disabled, and the framework default `can_short = False` (disclosed default, never a file literal) independently bars them.

**Risk (Gate 3, explicit):** the `adx > 60` signal exit is the sole position-ending path (`use_exit_signal = True` and `exit_profit_only = False` framework defaults apply — the exit fires even at a loss; disclosed defaults, never file literals). The file's ROI ladder, `-0.265` stoploss, and trailing block are explicitly disabled (see Provenance) — no profit trigger, no stop level, no trailing, no time stop, no partial exit, no averaging, no forced end-of-data liquidation, no silent executor default.

**State (Gate 4):** `FLAT_DISARMED`, `FLAT_ARMED`, `BUY_PENDING`, `LONG`, `SELL_PENDING`. Initialize `FLAT_ARMED` after 60 valid completed bars **only if E without the state clause was false on the immediately prior completed bar**; otherwise wait for a false bar to arm. A BUY request transitions to `BUY_PENDING`; only a confirmed MARKET fill at the next completed close transitions to LONG. A missing/failed/unconfirmed fill **halts** this research run; never synthesize inventory. While LONG, all entry predicates are ignored. SELL request transitions to SELL_PENDING; only a confirmed filled SELL of the complete 0.001 BTC returns to FLAT_DISARMED. Once flat, require at least one **subsequent** completed bar with the non-state entry predicate false to re-arm. No same-bar SELL+BUY, no pyramiding, **no DCA/safety orders (explicitly disabled — the downstream 6%+6%+6% house overlay is not active in this admission and never silently overrides single-unit semantics)**, no concurrency, no compounding, no session/cooldown. A pending order prohibits additional actions. An end-of-sample LONG is marked at the last real valid close, not closed with an invented fill.

## Required data / Gate 6 causality

**Warmup:** minimum 60 contiguous completed 1h bars before the first actionable bar; covers the 9-bar UD/DD seed, the ADX14 Wilder seed, the VAR recursion from index 2, the OTT two-bar shift, and the one-bar edge lookback, plus the arming rule. No warmup-bar trades; initial state and all rolling values start from the actual first historical bar, not from full-sample fitted statistics. Unseeded windows stay NaN and every NaN comparison is false — no leg can fire early. The file's own `startup_candle_count = 18` is disclosed but hardened to 60 here, never weakened.

Binance Kline `timestamp` is the **bar-open** `T[t]` (pinned `BinanceSpotCandles._parse_rest_candles` reads row[0]); a bar's OHLC and every derived line become available no earlier than `T[t]+3600s`. All decisions and fills are effective at completed-bar closes. The backtest engine's backward `merge_asof` operates on raw open-time indices, so a strategy-specific controller must gate features by close availability and not mistake open-time index `T[t]` for the decision time. No incomplete bar, higher-timeframe partial, future extremum, negative shift, repainting or same-bar intrabar touch is used — the prefix-stability probe above confirms appended future bars cannot revise past OTT/VAR values. The simulator's same-row-close fill is a **synthetic completed-bar convention**, not a real-world claim that a post-close order could capture the just-observed historical close. If this effective-time discipline cannot be enforced, Gates 5/6 fail in implementation.
